03 / DOMAIN为何在 Cloudflare 买域名06 / 09
域名与部署放在同一处

为什么在 Cloudflare 买域名？

01 / PRICE

注册续费不加价

只收注册局和 ICANN 的费用，没有额外加价。

02 / PRIVACY

个人信息默认脱敏

在注册局允许时，公开查询不会显示大部分个人资料。

03 / SETUP

部署少配几个系统

域名、DNS、Workers 和 HTTPS 可以在同一处完成。

绑定 Worker 后，Cloudflare 自动创建 DNS 并配置证书HTTPS READY

域名可以在其他平台购买后接入 Cloudflare；Cloudflare Registrar 还提供免费的一键 DNSSEC。

PROS / 优点

轻量，够用

  • 免费、隐私优先，不收集访客个人数据
  • 看访问量、来源、国家与设备
  • 自带 LCP、INP、CLS 性能指标
LIMITS / 局限

看趋势，不追人

  • 广告拦截器可能拦住埋点，访问会少记
  • 暂不支持 UTM 参数和自定义事件
  • 超过 7 天的数据会聚合，查询也可能抽样
适合个人网站看流量趋势和页面体验；复杂转化漏斗需要另配专业分析工具。
